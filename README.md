# ai-learning
## Неделя 1 - Учебные скрипты Python — неделя 1.
## Запуск
python hello.py
python calc.py
python words.py   # ввод текста, завершить Ctrl+Z Enter (Windows) или передать файл
## Что умеет
- hello.py — приветствие по имени и возрасту
- calc.py — калькулятор в цикле
- words.py — статистика по тексту

## Неделя 2 - Учебные скрипты Python — неделя 2.

### Запуск
python stats.py
python todo.py
python contacts.py
### Что умеет
- stats.py — статистика текста из файла
- todo.py — список задач (add / list / done / quit)
- contacts.py — справочник (add / find / delete / list / quit)

## Неделя 3 - Учебные скрипты Python — неделя 3.

### Запуск
python todo_save.py
python contacts_save.py
### Что умеет
- todo_save.py — список задач (add / list / done / quit), задачи сохраняются в файл tasks.json
- contacts_save.py — грузить контакты, добавлять, искать, удалять, показывать список, сохранять в в файл contacts.json
