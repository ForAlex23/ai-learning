# ai-learning
Учебные скрипты Python — неделя 1.
## Запуск
python hello.py
python calc.py
python words.py   # ввод текста, завершить Ctrl+Z Enter (Windows) или передать файл
stats.py # ввод расположения файла с текстом
## Что умеет
- hello.py — приветствие по имени и возрасту
- calc.py — калькулятор в цикле
- words.py — статистика по тексту
- stats.py — статистика по тексту из файла
